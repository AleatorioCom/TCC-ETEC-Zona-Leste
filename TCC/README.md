# Sementes Digitais

Aplicativo de catálogo de árvores da ETEC, com pedidos de novas plantas e aprovação pelo administrador.

## Para rodar

1. Clique em `instalar-banco.bat` e digite a senha do MySQL.
2. Clique em `start-server.bat` e deixe a janela aberta.
3. Abra no navegador: `http://localhost:8080/app/`
4. Para instalar no celular, use `dist/Sementes Digitais-1.0.0.apk`.

**Guia completo, bem passo a passo:** [GUIA_APP.md](GUIA_APP.md)

## Login do administrador

- E-mail: `admin@etec.sp.gov.br`
- Senha: `123456`

> O celular precisa estar na mesma Wi-Fi do PC. Se o catálogo não carregar, configure em **Perfil → Servidor da API**: `http://IP-DO-PC:8080/api`.
